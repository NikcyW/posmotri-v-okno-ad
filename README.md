# Посмотри в окно

Проектная работа для Яндекс.Практикума. Интерактивное веб-приложение для просмотра видео с видами на города в разное время суток.

## 🎯 Функциональность

- **Просмотр видео** — основной плеер с управлением воспроизведением
- **Список карточек** — прокручиваемый список городов с миниатюрами
- **Поиск по городам** — фильтрация видео по названию города
- **Фильтр по времени суток** — выбор утра, дня или ночи
- **Переключение видео** — клик на карточку меняет видео в плеере
- **Обработка ошибок** — уведомление если города не найдено
- **Прелоадеры** — индикация загрузки данных

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — flexbox, современные селекторы, анимации
- **JavaScript** — работа с DOM, обработка событий, работа с данными
- **Шрифты** — Fira Sans Condensed, Oswald

   ```

   ```

2. Используйте форму поиска чтобы найти видео по городу

3. Кликните на карточку чтобы переключить видео

## ⚙️ Оптимизация

- **Preload="none"** — видео не загружается до нажатия play
- **Canplay событие** — видео показывается как только первый фрейм готов
- **Mock данные** — работает локально без интернета

## 📋 Требования

- Браузер с поддержкой ES6 (Chrome, Firefox, Safari, Edge)
- Экран шириной ≥ 1200px (оптимально)
